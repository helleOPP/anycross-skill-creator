# AnyCross Creator

**Describe a Lark automation in plain words, get a ready-to-import AnyCross workflow.** An AI agent skill for Lark/Feishu AnyCross (Claude Code, Cursor, Codex, Gemini CLI).

## Install

```bash
npx skills add helleOPP/anycross-skill-creator
```

Needs Python 3.8+. Or copy `anycross-creator/` into `~/.claude/skills/`.

## Use

Ask your agent:

> Every day at 6am, read the pending rows from my Lark Base and post a summary card to a Lark group.

You get a `.zip`. In AnyCross: Workflow → **+** → **Import Workflow**.
